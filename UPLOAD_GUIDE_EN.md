# GitHub Upload Guide

Repository name: `ball-and-beam-control-system`

1. Extract the ZIP archive to a local folder.
2. Open your GitHub repository on the `main` branch.
3. Select **Add file → Upload files**.
4. Drag **the contents of the extracted folder** into the upload area, not the ZIP itself or its parent folder.
5. Review that `README.md` is at repository root, with `models/`, `docs/`, `matlab/`, and `media/` directly beside it.
6. Commit with `Initial commit: document ball and beam control project`.
7. Confirm that the images and model links render in the README.
8. If the GitHub web uploader rejects the video batch, upload videos separately or use GitHub Desktop. Avoid uploading duplicate copies of large files.

Suggested description:
`Ball-and-beam control project featuring linear and nonlinear modeling, Simscape Multibody, PID experiments, and an Arduino-based hardware prototype.`
